# funpayhub-top-tools
FunPayHub — бесплатное браузерное расширение для автоматизации продаж на FunPay. Поддерживает автоподнятие лотов по расписанию, быстрые шаблоны ответов в чатах, автоответы на отзывы и улучшение интерфейса площадки. Помогает продавцам экономить время, удерживать объявления в топе и ускорять обработку заказов в браузерах.
