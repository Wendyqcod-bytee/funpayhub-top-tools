# FunpayHub

Расширение для Chrome / Edge / Brave / Opera (Manifest V3).

## Установка
1. Распакуйте архив.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`), включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `funpayhub`.
4. Войдите в аккаунт на funpay.com. В шапке рядом с профилем появится кнопка FunpayHub.

## Возможности
- Окно по центру экрана: приветственный экран, свернуть (−) и закрыть (✕), поиск по разделам
- Автоподнятие лотов, уведомления (в браузере и в Telegram), быстрые ответы и слэш-команды
- Чёрный список, копилки, калькулятор комиссии, конвертер валют, заметки
- Статистика сумм на странице «Продажи»

## Как устроено (оптимизация)
- `content/gui.js` — лёгкий загрузчик (кнопка в шапке, акцент, снег).
- `content/panel.js` — вся панель; подгружается только при первом открытии.
